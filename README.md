# 2026国庆出游计划

常州往返，皖南 / 浙江两条独立的纯电床车路线。支持 2026 年 10 月 2–6 日、2–7 日、3–7 日三种日期窗口。5 天与 6 天内容独立编排，共 32 个可切换每日页面。

安徽线：常州 → 泾县 → 桃花潭 → 黟县卢村观景台 → 黟县 → 西溪南 → 岩寺 → 呈坎 → 广德市区 → 常州。6 天版酒店在岩寺，5 天版在黟县。卢村指黟县卢村，非广德卢村镇。

浙江线：常州 → 桐庐 / 深澳 → 松阳（仅 6 天版）→ 缙云 / 仙都 → 桐庐 → 常州。不叠加台州、乐清与登高路线。

线上：https://uuurary.github.io/national-day-roadbook-2026/

## 这是哪一种 TREK 适配

参考 TREK 的公开分享行程数据组织方式，改写为完全静态的网页。
保留地图、日期、景点、补能、住宿提示、预算、行李清单以及本地备忘。
**这不是完整 TREK 实例，不提供账户、后台数据库、在线多人编辑或跨设备清单同步。**
页面附带的 `*-trek-snapshot.json` 是与公开分享字段结构对应的快照，
不是 TREK 数据库备份，也未声称可由 TREK 一键导入。

## GitHub Pages

1. 将本仓库推送到个人 GitHub 的 `main` 分支。
2. 仓库 Settings → Pages → Source 选择 **Deploy from a branch**。
3. 选择 `main` 分支、`/ (root)` 目录。GitHub 将自动发布根目录中的静态文件。

此方式不需要额外申请 GitHub `workflow` 权限；提交前在本地运行测试和构建。

使用 GitHub Pages 静态托管。没有 Codex Sites、服务器、云数据库、API密钥或外部托管后端。
地图瓦片来自 OpenStreetMap；道路几何在构建前缓存，浏览器不调用 OSRM。
所有链接相对寻址，支持 `https://用户名.github.io/仓库名/` 子路径。

## 信息边界

- 两人、一位驾驶员、实际续航 450 km。按所选日期和路线预留 1 晚酒店，其余车宿；疲劳可加酒店。没有实际预订。
- 地图仅用城市/镇区锚点，不代表精确景点入口、充电桩或已获准夜宿停车点。
- 住宿未预订，充电实时枪位未核实。预算/道路耗时为规划区间。
- 勾选/备忘只保存到本机浏览器；清除浏览器数据会丢失。
- 城市间路线是OSRM参考，不含实时交通。缓存缺失的段落使用标注清楚的虚线方向示意。
- 公开站点仅包含常州市区起点与旅游规划，不含精确家庭住址、订单或账户凭据。

## 天气与本地存储

天气通过浏览器请求 Open-Meteo 免费接口，按经过城市和实际旅行日期精确匹配，最多查询未来 16 天。第 8–16 天只作为中期趋势。显示来源和获取时刻，模型发布时间未提供；不在范围、数据异常、网络失败时显示“待更新”，仅给通用穿搭。官方预警另通过中国天气网和景区通知核实。天气测试使用固定响应，不冒充真实天气。

清单、备注及选择保存在当前站点的 localStorage，键为 `national-day-2026-v2`。不上传、不跨设备同步；隐私模式或清理数据可能丢失。存储被禁用时显示仅临时保存。旧版勾选键不删除、不按新 ID 强行映射。
